# Crypto Strategy Backtester & Analyzer

A high-performance cryptocurrency backtesting platform and visual charting workbench built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- **Long-Term & Multi-Timeframe Backtesting**: Test algorithmic strategies on 1W, 1M, multi-day, and intraday timeframes.
- **Custom Date Ranges**: Select preset execution cycles (1W, 1M, 2M, 3M, 6M, 1Year) or specify exact custom calendar dates.
- **Strategy Engine**:
  - EMA Golden/Death Cross
  - RSI Overbought/Oversold & Divergence
  - MACD Momentum Cross
  - Bollinger Bands Mean Reversion
  - Supertrend Trend Following
  - Multi-Condition Custom Rule Builder
  - Pine Script-inspired Strategy Mode
- **Interactive Candlestick Chart**: HTML5 Canvas-powered interactive charting with zoom, pan, support & resistance lines, drawings, and indicator overlays.
- **Performance Analytics**: Win rate, profit factor, max drawdown, Sharpe ratio, cumulative equity curve, and detailed trade log.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
